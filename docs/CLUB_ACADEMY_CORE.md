# Club & Academy Core V1

## Organization profile
- Identity, logo, country, city and description
- Club vs Academy type
- Verification status
- International programme flag
- Authorized administrators

## Recruitment
Organizations create recruitment needs with:
- position
- age range
- preferred foot
- level
- country preference
- requirements
- status: open / paused / closed

## Candidate pipeline
`Discovered -> Shortlisted -> Contacted -> Trial -> Signed`

A candidate can be rejected from any active stage. Invalid stage transitions must be rejected server-side.

## Candidate workspace
Each candidate card should expose only authorized player information and show:
- Atlas Score when available
- Match Score
- Match confidence
- reasons
- missing information
- verification status
- current pipeline stage

## Opportunity bridge
An open recruitment need can generate an Opportunity view so eligible players can discover/apply when the organization chooses to make it public.

## Organization roles
Club Admin and Academy Admin manage only their organization. Atlas Staff can support multiple organizations according to assigned permissions. Super Admin manages the system.
