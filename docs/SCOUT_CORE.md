# Scout Core V1

Scout is a first-class Atlas role connecting discovery, evaluation and recruitment.

## Scout profile
- Countries / regions
- Age groups
- Positions
- Specialties: talent ID, technical, tactical, physical, goalkeeper, youth, international
- Verification status

## Workflow
`Discover → Watchlist → Evaluate → Report → Shortlist → Opportunity/Trial`

## Watchlist
Each item has priority, notes, status and timestamps. Private player information remains permission-controlled.

## Assignments
Atlas Staff or authorized organizations can assign scouting tasks with due dates and status.

## Reports
Reports capture technical, tactical, physical, mentality and professionalism ratings plus strengths, weaknesses and recommendation.

Recommendations: Monitor, Shortlist, Trial, Sign, Not Recommended.

## Search integration
Scout Search uses Atlas Search but is permission-aware. Scouts must never gain access to private player data merely because a player appears in a search result.
