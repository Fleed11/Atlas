# Atlas Internationalization

Supported locales: `en`, `es`, `fr`, `ar`.

Arabic is full RTL. Use CSS logical properties (`margin-inline`, `padding-inline`, `inset-inline`) and set document direction dynamically.

All interface copy must use translation keys. No hard-coded UI labels.

Core keys include:
- nav.dashboard
- nav.search
- nav.profile
- nav.score
- nav.development
- nav.opportunities
- nav.reports
- nav.calendar
- nav.messages
- nav.documents
- player.atlas_score
- player.profile_completion
- opportunity.apply
- common.verified
