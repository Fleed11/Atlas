# ATLAS — Global Football Platform

**Your Football World. One Place.**

Atlas is a multilingual football ecosystem connecting players, families, scouts, clubs and academies through identity, scouting, search, matching and opportunities.

## V1
- Player Portal
- Parent Portal foundation
- Scout Portal foundation
- Club / Academy foundation
- Atlas Search
- Atlas Match
- Atlas Score
- Development / Objectives
- Highlights / Reports
- Opportunities / Trials
- CRM / Admin foundation
- English / Spanish / French / Arabic (RTL)

## Starter stack
React + TypeScript + Vite + Lucide. Persistence and authentication should be wired to Base44 entities/actions when imported.

See `docs/BASE44_IMPLEMENTATION.md` for the implementation brief and `docs/DATABASE_SCHEMA.md` for the data model.
